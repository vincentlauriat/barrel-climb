Under the hoodSous le capot幕後原理

  • The game is a pure functionLe jeu est une fonction pure遊戲是一個純函式

    The simulation is a Swift package that imports no UI framework, no clock and no system random source. It advances by exactly 1/60 s from an input struct and a seeded random source, and hands back the list of things that happened. That is why 76 deterministic tests cover every rule on this page and finish in hundredths of a second, without ever opening a window.La simulation est un package Swift qui n'importe aucun framework d'interface, aucune horloge et aucune source aléatoire du système. Elle avance d'exactement 1/60 s à partir d'une structure d'entrées et d'une source aléatoire à graine, et renvoie la liste de ce qui s'est passé. C'est pourquoi 76 tests déterministes couvrent chaque règle de cette page et s'exécutent en quelques centièmes de seconde, sans jamais ouvrir de fenêtre.模擬是一個 Swift 套件，不匯入任何 UI 框架、時鐘或系統亂數來源。它根據一個輸入結構與一個帶種子的亂數來源，每次精確前進 1/60 秒，並回傳發生事件的清單。正因如此，76 個確定性測試涵蓋了本頁的每一條規則，而且在百分之幾秒內就跑完，完全不必開啟視窗。

  • The screen only mirrors itL'écran ne fait que la refléter畫面只是它的鏡像

    One SpriteKit scene of 224 x 256 logical points copies the world into sprite nodes after each step and turns the returned events into sound. It never owns game state. Fitting that picture to the display is a single setting, which is the entire foldable-phone support, and one Xcode target covers macOS and iOS from one generated project.Une seule scène SpriteKit de 224 x 256 points logiques recopie le monde dans des nœuds de sprites après chaque pas et transforme les événements renvoyés en sons. Elle ne possède jamais l'état du jeu. Adapter cette image à l'écran tient en un seul réglage, qui constitue tout le support des téléphones pliables, et une seule cible Xcode couvre macOS et iOS depuis un projet généré unique.一個 224 x 256 邏輯點的 SpriteKit 場景，會在每一步之後把世界複製到 sprite 節點中，並把回傳的事件轉成聲音。它從不持有遊戲狀態。讓畫面符合螢幕只需一項設定，這就是對折疊手機的全部支援；而一個 Xcode target 就從單一產生的專案涵蓋 macOS 與 iOS。

Every sprite and every sound here is generated by a Python script in the repository.Barrel Climb est une œuvre originale de Vincent Lauriat.
