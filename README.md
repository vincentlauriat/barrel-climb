# Barrel Climb (codename DonkeyKong)

Landing page: https://vincentlauriat.github.io/barrel-climb/

An original arcade platformer for macOS and iOS (including iPhone Duo in both fold
states): climb six inclined girders, dodge barrels, grab hammers, rescue the captive.
Mechanics inspired by the 1981 classic; every sprite and sound is generated by the
scripts in `Tools/` — no third-party assets.

## Run

Requires Xcode 27, macOS 14+, Python 3 for asset regeneration.

    make run-mac          # macOS window
    make build-ios        # then install the .app on a simulator:
    xcrun simctl boot "iPhone 17 Pro" || true
    xcrun simctl install booted build/DerivedData/Build/Products/Debug-iphonesimulator/DonkeyKong.app
    xcrun simctl launch booted fr.lauriat.DonkeyKong

## Controls

| Action | macOS | Controller | iPhone |
| --- | --- | --- | --- |
| Move / climb | Arrows or WASD | D-pad / left stick | Left pad |
| Jump / start | Space | A | Right button |

## Develop

    make test             # simulation core, deterministic, no simulator
    make build-mac build-ios
    make lint
    make sprites sounds   # regenerate assets

The simulation lives in `Core/` (pure Swift, fixed 1/60 s steps, injected RNG) and the
SpriteKit app in `App/`. See `CLAUDE.md` for the architecture rules.
